# 基金分析產品定位與「長期低頻」前端面板設計思考

## 1. 市場定位：大眾流量 vs 利基價值
- **流量現況**：大眾投資注意力高度集中在台美股個股、高股息/市值型 ETF、加密貨幣；共同基金/境外基金的點閱率與泛大眾流量相對偏低。
- **利基價值**：
  - **受眾資產含金量高**：關注基金與多元資產配置者，平均可投資金額（AUM）較高。
  - **避開紅海**：ETF/個股分析競爭極度內卷，但專注於「客觀同組篩選」與「歷史回撤修復（Recovery）」的獨立工具極少。
  - **商業模式**：適合走高品質工具、客製化配置諮詢或精準分潤，而非靠廣告點擊（AdSense）。

## 2. 核心洞察：長期投資的「低頻查看」矛盾
> **「因為是長期，感覺不會常看。」**

- **傳統看盤面板的痛點**：充滿即時報價、紅綠跳動的儀表板適合短線交易，長期投資人看了只會增加焦慮或因為日常波動做出錯誤決策，久了便不再打開。
- **範式轉變**：長期投資工具不應是「日常監控儀表板（Monitoring Dashboard）」，而應是**「事件驅動與資產守護型系統（Steward & Event-Driven System）」**。
- **設計哲學**：平時不打擾、有事主動通知；一年只開幾次，每次打開 30 秒內即可完成評估或決策。

## 3. 面向「低頻高價值」的五大核心面板功能
1. **回撤歷史尺規與逆勢加碼導航（基於 `recovery.ts`）**：
   - 平時不看盤，崩盤時才看。
   - 呈現當前跌幅在歷史最大回撤（MDD）中的百分位、歷史水下修復天數、1 年後回正機率，提供情緒價值與逆向加碼信心。
2. **留校察看與汰弱留強警訊（基於 `screen.ts`）**：
   - 解決主動型基金跑輸同類的隱形風險。
   - 採用極簡紅黃綠三色燈：同組排名前段（綠燈）、近半年後 40%（黃燈/留校察看）、連續一年落後（紅燈/建議替換候選）。
3. **被動體檢月報/季報 Digest（整合 Discord / Webhook）**：
   - 季底或月結自動發送一頁式摘要。
   - 若持倉皆健康，推播「無事報平安」，不必逼用戶登入網頁。
4. **年度再平衡（Rebalancing）試算器**：
   - 設定目標資產配置比（如股債比）。
   - 自動試算定期定額動態調整金額或單筆買賣建議，省去手動計算摩擦。
5. **投資初衷備忘錄（Investment Thesis）**：
   - 買入時記錄核心理由，在恐慌想拋售時彈出提醒，抵抗追高殺跌的人性弱點。

## 4. 技術與架構對接
- **後端既有優勢**：Cloudflare Worker + D1 + Hono，提供毫秒級同組篩選與回撤計算 API。
- **前端部署建議**：採用 Cloudflare Pages 靜態/輕量 SPA 部署，同享 Cloudflare 邊緣快取，零主機維護成本、極致秒開體驗。
- **MVP 第一步**：不先做 4,500 檔的搜尋大海，優先做「3~5 檔觀察名單（Watchlist）一頁式體檢卡片」。

**Implications**：
後續規劃前端 UI 時，避免陷入傳統金融網頁「塞滿行情資訊」的思維。界面設計應以「極簡狀態指示（紅黃綠）」、「歷史回撤進度」及「30 秒決策導向」為最高原則。
